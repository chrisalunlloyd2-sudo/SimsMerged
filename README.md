# SimsMerged Metropolis v1.3: The Darwinistic System Simulation

![Metropolis Screenshot](assets/Final_Boss_Environment_Screenshot.png)

## Overview
**SimsMerged Metropolis** is a high-fidelity, autonomous system simulation that translates complex computer architecture into a thriving "Urban Metaphor." Built upon the 1700-step Darwinistic merge of SimAgentCity and JavaFX_Neo, it provides a visual and agentic representation of hardware telemetry, protocol trajectories, and systemic health.

## 🏛️ The 6 Cities of Silicon
The metropolis is divided into six functional districts, each representing a core subsystem:
1.  **Silicon Central (CPU):** Where logic and instruction execution happen.
2.  **Memory Matrix (RAM):** The volatile data storage heart.
3.  **Graphics Grid (GPU):** Parallel processing and ray-tracing trajectories.
4.  **Storage Hive (Disk):** Non-volatile data integrity and storage nodes.
5.  **Kernel Hub (OS):** The administrative bridge and configuration registry.
6.  **Protocol Port (Network):** The gateway to the global data web.

## 🧠 AI Agentic Network
The grid is inhabited by specialized AI kernels:
- **ADMIN_ROOT:** The ultimate authority, purging low-level processes to maintain stability.
- **SI_AGENT (Suicide Inhibitor):** Binds to failing kernels to prevent systemic collapse.
- **NURSE/DOCTOR:** Healers that restore stability to bound kernels.
- **BOUNCER:** Security agents that hunt and evict rogue processes (bugs).

## 🚀 Quick Start
### Prerequisites
- Python 3.x (FastAPI)
- Java 17+ (JavaFX)
- Maven
- Modern Web Browser

### Launch Sequence
1.  **Start Backend:**
    ```bash
    python backend/main.py
    ```
2.  **Launch Web Dashboard:**
    Open `frontend/index.html` in your browser.
3.  **Run Java Engine (Optional):**
    ```bash
    mvn javafx:run
    ```
