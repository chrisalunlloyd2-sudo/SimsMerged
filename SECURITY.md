# Security Policy

## Supported Versions
Only the latest version of SimsMerged Metropolis is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within SimsMerged Metropolis, please send an e-mail to security@simsmerged.metropolis. All security vulnerabilities will be promptly addressed.
