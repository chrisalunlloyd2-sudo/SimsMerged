# Frequently Asked Questions (FAQ)

### What is SimsMerged Metropolis?
It is a high-fidelity Darwinistic system simulation that represents computer architecture as an autonomous urban environment.

### How do I run the simulation?
Refer to the Quick Start section in the README.md.

### Can I add new types of agents?
Yes! Please see CONTRIBUTING.md for guidelines on how to propose and implement new agentic kernels.

### Is this a game or a tool?
It is both. It's a visualization tool for system telemetry and a Darwinistic sandbox for testing agentic stability.
