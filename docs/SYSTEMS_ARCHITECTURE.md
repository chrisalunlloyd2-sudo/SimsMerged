# SYSTEMS ARCHITECTURE: METROPOLIS CORE (v1.3)

## 🏗️ Architectural Philosophy
SimsMerged utilizes an **Urban Metaphor** to visualize the invisible flows of a computing environment. By mapping hardware components to buildings and data packets to metropolitan transit, the system provides an intuitive, high-signal interface for system monitoring and agentic interaction.

## 🌉 The Neural Bus & Trajectories
Data movement is visualized through varying trajectories:
- **Local Bus (Red Lasers):** High-speed, straight-line data within Silicon Central.
- **System Bus (Neon Neon):** High-bandwidth pipelines between CPU and RAM.
- **PCIE Arcs (Parabolic):** Long-distance "leaps" to GPU and Storage.
- **Network Protocols:**
    - **TCP/IP:** Reliable "Walking" packets.
    - **UDP:** Jittery "Bike" packets.
    - **HTTP:** Standard "Car" transit.

## 🛡️ Safety & Stability Hard-Locks
To ensure simulation integrity, the system implements several "Immutable" layers:
- **BIOS Hard-Lock:** Firmware settings are anchored at the silicon level and cannot be modified via GUI.
- **Infrastructure Anchors:** Core hardware buildings (CPU, RAM, GPU) are non-deletable fixtures of the grid.
- **Isolation Layer:** Sensitive environment data is restricted to `local_env/` and excluded from source control.

## 🧬 Agentic Symbiosis
The relationship between agents is one of mutual maintenance:
1.  **Detection:** The SI_AGENT detects a "Depressed Kernel" (Stability < 20%).
2.  **Binding:** The SI_AGENT anchors the kernel with a visual magenta chain.
3.  **Restoration:** NURSE/DOCTOR agents navigate to the anchored node to apply restoration logic.
4.  **Purge:** If restoration fails, ADMIN_ROOT executes a "Purge" command to clear the node and reclaim resources.
