# MERGE DOCUMENTATION: SIMS MERGED GENESIS

## Overview
This document records the official architectural merge between **SimAgentCity** (FastAPI/AI Orchestrator) and **Sims_JavaFX_Neo** (JavaFX Game Engine) into the unified **SimsMerged** ecosystem.

## Component Integration
1.  **AI Engine:** Integrated the `backend/` Python logic for agent lifecycle management and FastAPI endpoints.
2.  **Visual Engine:** Merged the JavaFX source code (`src/main/java`) into the repository for native desktop simulation.
3.  **Web Bridge:** Deployed a high-fidelity Isometric Web Engine (`frontend/`) to visualize the system topology in-browser.
4.  **Hardware Virtualization:** Integrated the 14-node component suite (CPU, RAM, GPU, Registry, etc.) into the world-state.
