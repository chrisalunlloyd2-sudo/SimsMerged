# DARWINIAN DESIGN SPECIFICATION: SIMSMERGED v1.3 (METROPOLIS EDITION)

## The High-Fidelity Data Metropolis
SimsMerged has evolved from a simple system sandbox into a sprawling, high-fidelity data metropolis. The philosophy has shifted to **Data-First Simulation**, where physical hardware is environmental infrastructure, and the core gameplay resides in the "Data Layer."

### 1. Urban Topology & Infrastructure
- **Data Districts:** Tall glass-morphism panels representing software nodes (VS Code, LLM Node, Docker).
- **Hard-Locked Infrastructure:** Darkened, recessed bases for environmental constants (CPU Cluster, BIOS, Modem).
- **Urban Enrichment:** 100+ logical decorations, including Logic Trees, Neon Streetlamps, and Cyber-Vignettes.
- **Neon Thoroughfares:** Highlighted grid lines acting as major data roads.

### 2. Behavioral Mapping Protocols
- **AI Kernels:** Autonomous entities named after historical machine architectures (Darwin, Mach, NT).
- **Specialized Roles:**
  - **ADMIN_ROOT:** System authority that purges low-level background processes for resource reclamation.
  - **SI_AGENT (Suicide Inhibitor):** A high-priority sentinel that binds to failing kernels to prevent systemic cascades.
  - **Healers (Nurse/Doctor):** Focused on restoring stability to depressed kernels.
  - **RAM Watchers:** Sentinels resident in memory nodes monitoring allocation pressure.

### 3. Visual Protocol Pipes
Connections are no longer static points but functional visual conduits:
- **Internal BUS:** Straight, high-speed neon lines for on-die traffic (CPU <-> RAM).
- **Network Protocols:** Large parabolic arcs with visual jitter (UDP wobble) for over-the-wire transit (Modem <-> Web).

### 4. Advanced System Dashboard
- **Parameter Suite:** Extensive sidebar for pre-deployment configuration (TDP, token limits, multipliers).
- **Information Veil:** Deep-hover telemetry tooltips with elegant formatting and exhaustive technical descriptions.
- **Cinematic Overlays:** CRT scanlines and atmospheric vignettes for a professional "Hard-Console" feel.

### 5. Ethical & Safety Hard-Locks
- **BIOS Immutable:** Core firmware values are hard-coded and untouchable by any user/agent command.
- **Frustum Culling:** Real-time optimization ensuring performance even with exhaustive urban density.
