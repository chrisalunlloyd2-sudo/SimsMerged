# Contributing to SimsMerged Metropolis

First off, thank you for considering contributing to SimsMerged Metropolis! It's people like you that make this Darwinistic simulation thrive.

## How Can I Contribute?

### Reporting Bugs
Bugs are tracked as GitHub issues. When creating a bug report, please include as many details as possible to help us reproduce the issue.

### Suggesting Enhancements
Enhancement suggestions are also tracked as GitHub issues. Provide a clear and concise description of the proposed enhancement.

### Pull Requests
1. Fork the repo and create your branch from main.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Issue that pull request!

## Styleguides
### Git Commit Messages
* Use the present tense ("Add feature" not "Added feature")
* Use the imperative mood ("Move cursor to..." not "Moves cursor to...")
* Limit the first line to 72 characters or less
